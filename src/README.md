# Staged RGBDS source

`game.asm` assembles an initial staged reconstruction. `bank_000.asm` is a working copy of the bank-0 disassembly. Confirmed labels/comments now clarify the MBC5 bank-call wrappers, the `$007A` `DecompressFromBank` wrapper, the `$124C` `DecompressBackReferenceStream` control groups/tokens/return convention, the `$10C0-$1163` CGB tilemap fill/copy helpers, the `$1188` 16-byte copy loop, `$11C2` STAT-synchronized copies, the `$23A8` tile transfer, and other traced helpers. The decoder returns `DE` = output end and `HL` = decoded byte count. Original instruction bytes and layout are retained; all behavior claims are documented in `../docs/KNOWN_ROUTINES.md`.

`bank_004.asm` is a working copy of bank 4. The dispatched graphics setup at `$5C42` is labeled `SetupBank4GraphicsState`; its caller and tile-transfer parameters are documented in `../docs/KNOWN_ROUTINES.md`. The nearby `$5E11`, `$5E42`, and `$5E8C` routines have behavior-based labels. Bank-0 `$0DD4` is now `ProcessBankedRecord`; its memory and bank-switch behavior is traced, though the `$D7xx` field meanings and overall record purpose remain unknown. The `$5E42` caller is not established. The 42-tile range at CPU `$627F` (file offset `$01227F`, length 672 bytes) is replaced with a generated `INCBIN`. `make -C src` converts the editable indexed image `../gfx/bank4_627F_tiles.png` to `../build/bank4_627F_2bpp.bin` using RGBDS `rgbgfx`. The original raw extraction `../gfx/bank4_627F_2bpp.bin` is retained as an untouched reference. No character names are assumed.

Banks 1–63 and the rest of bank 0 still come from the disassembly in `../analysis/disassembly/`; their presence in a successful build does not mean they are fully understood or editable in a semantic sense.

Build from the project root with `make -C src`. This writes `build/step7.gbc` and related RGBDS outputs without touching the original ROM or the existing baseline build. Compare the output with `../tools/rom_analysis.py compare ../rom/original.gbc ../build/step7.gbc`.
